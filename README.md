# Cat vs Dog Classifier

A simple Streamlit app that trains a logistic regression model on cat and dog images and predicts the class of uploaded images.

## Run locally

```bash
pip install -r requirements.txt
streamlit run train.py
```

## Deploy on Streamlit Cloud

1. Push this project to GitHub.
2. Open Streamlit Cloud.
3. Create a new app and select the repository.
4. Set the main file path to `train.py`.
5. Deploy.
